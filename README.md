Mini Catálogo Web -Projeto Cafeteria

Um mini site ilustrativo de catálogo desenvolvido com foco em estrutura simples, organização de conteúdo e apresentação visual de produtos/itens. Este projeto serve como base para estudos e futuras evoluções com tecnologias mais dinâmicas.

- Objetivo

Criar uma interface básica de catálogo que simule a exibição de produtos de forma clara e organizada, utilizando apenas tecnologias essenciais do front-end.

- Tecnologias Utilizadas
HTML5
CSS3
- Estrutura do Projeto
/projeto
│── index.html
│── /css
│     └── styles.css
│── /img
│     └── (imagens do catálogo)

Funcionalidades Atuais
Exibição de itens em formato de catálogo
Layout organizado e responsivo básico
Estilização visual com CSS
Estrutura simples e de fácil entendimento

- Próximas Melhorias

Modal ou página de detalhes do produto

Animações e transições para melhor experiência do usuário

-Possíveis Expansões
